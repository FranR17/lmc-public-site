# LMC — sitio informativo

Sitio estático de presentación, términos y privacidad de LMC.

Responsable del proyecto: **Mr X. Clips**.
Contacto público: **n8nclient2000@gmail.com**.

## Archivos del sitio

- `index.html`: presentación y descripción de la aplicación local.
- `terms.html`: términos de servicio.
- `privacy.html`: política de privacidad.
- `styles.css`: presentación adaptable a móvil y escritorio.
- `icon.svg`: icono de LMC.
- `.nojekyll`: sirve los archivos estáticos directamente en GitHub Pages.

No se incluyen aquí el programa, proyectos, vídeos, configuraciones ni credenciales
de una instalación de LMC. Las páginas no incorporan formularios de acceso.

## Alojamiento

Preparado para servir la raíz de la rama `main` con GitHub Pages. Los enlaces son
relativos para funcionar también bajo el prefijo de un repositorio.

Al cambiar el funcionamiento de la aplicación o sus tratamientos de datos, revisar
y actualizar las páginas y su fecha antes de publicar esos cambios.
